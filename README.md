## Funcionalidades

- Cadastro de produtos com nome, preço e quantidade em estoque.
- Validação dos dados informados antes da conclusão do cadastro.
- Listagem dos produtos cadastrados.
- Cálculo do valor em estoque de cada produto, considerando preço e quantidade.
- Menu interativo para navegação entre as funcionalidades.

## Tecnologias e conceitos

- **Linguagem:** C#
- **Plataforma:** .NET
- **Paradigma:** Programação Orientada a Objetos (POO)
- Classes, objetos e propriedades.
- Coleções com `List<T>`.
- Estruturas condicionais: `if`, `else if` e `else`.
- Estruturas de repetição: `do-while` e `foreach`.
- Validação de dados.
- Operações matemáticas e manipulação de dados.

## Como executar

### Pré-requisitos

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Git](https://git-scm.com/downloads)

### Instalação

**1. Clone o repositório:**

```bash
git clone https://github.com/Ryan3103/Cadastro-de-Produtos.git
```

**2. Acesse o diretório do projeto:**

```bash
cd Cadastro-de-Produtos/CadastroDeProdutos
```

**3. Execute a aplicação:**

```bash
dotnet run
```

## Observações técnicas

- Os dados são mantidos em memória durante a execução da aplicação.
- Os produtos cadastrados não são preservados após o encerramento do programa.
- O cadastro rejeita nomes vazios e valores negativos para preço ou quantidade.
- A aplicação ainda não utiliza banco de dados nem persistência em arquivos.

## Objetivo do projeto

Este projeto tem como objetivo consolidar conhecimentos fundamentais de C# e introduzir conceitos de Programação Orientada a Objetos por meio do desenvolvimento prático de uma aplicação de gerenciamento de produtos.
